Frequently Asked Questions

Are files or messages uploaded to a central server?

No. PeerBox is 100% serverless. All data streams directly browser-to-browser via WebRTC data channels with zero server storage, logging, or relaying.

What is the maximum file transfer size in PeerBox?

There is no hard-coded file size limit. Files 25MB and larger stream directly into the browser's Origin Private File System (OPFS), supporting multi-gigabyte transfers.

How does end-to-end encryption work without accounts?

The secret Room Key resides strictly in the URL hash fragment (#key=...), which browsers never transmit over HTTP requests. Encryption keys are derived client-side via Web Crypto AES-GCM.
