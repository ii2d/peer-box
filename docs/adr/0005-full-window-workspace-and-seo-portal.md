# Full-Window Workspace and SEO Portal

PeerBox bifurcates its presentation between a public, crawlable, semantic **Portal** at `/` (engineered for search engines and AI LLM discovery with structured JSON-LD, feature explainers, and architectural trust guarantees) and an edge-to-edge, full-window (`100vw` × `100dvh`) **Room** workspace (desktop 2-column Roster and Timeline, responsive mobile drawer). This resolves the tension between discoverability for a zero-server static site and the ergonomic demands of a focused, distraction-free real-time communication tool.
