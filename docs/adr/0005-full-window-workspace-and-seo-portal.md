# Full-Window Workspace, Minimal Portal, and Zero-JS Static Documentation

PeerBox trifurcates its presentation between:

1. A minimal, focused, centered **Portal** at `/` (clean entry surface with centered room creation/join card and lightweight SoftwareApplication JSON-LD),
2. An edge-to-edge, full-window (`100vw` × `100dvh`) **Room** workspace (desktop 2-column Roster and Timeline, responsive mobile drawer), and
3. High-performance, zero-JS static documentation pages (`/about/`, `/faq/`, and `/privacy/`) hosting deep architectural specs, Schema.org `HowTo`/`FAQPage`/`AboutPage` structured data, and verifiable trust guarantees.

This resolves the tension between ergonomic simplicity for real-time human users, robust discoverability for search engines and AI agents, and frictionless static hosting on GitHub Pages with zero client-side routing hacks.
